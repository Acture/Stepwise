# Stepwise

Rust exercises for Python evaluation and propositional logic.

- Use tabs and explicit types.
- Keep teaching rules separate from terminal rendering.
- Run cargo fmt --check, cargo clippy --locked --all-targets -- -D warnings, and cargo test --locked.
- User instructions live in README.md. Internal planning and verification records are private.
- AGENTS.md and .github/copilot-instructions.md point to this file.

# 符号与规则

本页供做题或编题时查询。操作方式见[开始做题](usage.md)，题目文件格式见[编写题集](question-sets.md)。

## Python 运算

支持变量、整数、有限浮点数、`True`、`False`、`None`，以及下列运算：

| 类别 | 写法 |
| --- | --- |
| 算术 | `+ - * / // % **` |
| 一元运算 | `+x`、`-x`、`not x` |
| 比较 | 单个 `== != < <= > >=` |
| 布尔组合 | `and`、`or` |

语法保留 Python 的大小写、优先级与结合关系。暂不支持字符串、调用、容器、赋值语句、链式比较、位运算或复数。

替换答案区分类型：`False`、`0`、`0.0` 不可互换。浮点答案严格比较，包括负零，不使用误差阈值。`//` 和 `%` 遵循 Python 的负数规则；`and` / `or` 返回决定结果的操作数，保留其类型。

同优先级的独立子式可以任选先后，例如 `(2+3)*(4+5)` 可以先算右边。原有结合关系不能改变，`20-5-2` 不能选 `5-2` 作为一步。变量可随时统一代入；每层括号内只剩值后，点击该层括号即可去掉它。

最终整个式子只剩负号和一个非负数时，直接完成，不再要求填写一次相同的负数。中间的取负、双重负号和布尔值转数值仍需处理。负数幂底数的必要括号会保留：`(-2) ** 2` 不能显示成含义不同的 `-2 ** 2`。

## 命题逻辑符号

求值与自然演绎接受相同的别名。求值界面保留输入写法，自然演绎统一显示逻辑符号。

| 联结词 | 等价写法 |
| --- | --- |
| 非 | `¬`、`~`、`∼`、`!`、`not` |
| 且 | `∧`、`&`、`&&`、`and` |
| 或 | `∨`、`\|`、`\|\|`、`or` |
| 蕴涵 | `→`、`⇒`、`⊃`、`->`、`=>` |
| 等价 | `↔`、`⇔`、`≡`、`<->`、`<=>` |

真值可写 `True/False`、`true/false`、`T/F`、`⊤/⊥`、`真/假`。命题名使用英文字母开头的标识符，`T` / `F` 保留为真值。优先级从高到低为非、且、或、蕴涵、等价；蕴涵右结合。可用括号明确结构。暂不支持量词、谓词或模态逻辑。

## 短路与额外计算

Python 的 `and` / `or`，逻辑的 `∧`、`∨`、`→`，在已有操作数决定结果时允许直接短路。也可以继续计算会被跳过的操作数，算到一半后仍可选择短路。每一步自行选择，不需要切换模式。`↔` 需要两边的值。

例如 `False and (3 / 0 > 1)` 可以直接填 `False`，也可以选择 `3 / 0` 并填写 `ZeroDivisionError`。后一种选择会结束本次求值，反馈说明异常来自所选子式；按 `u` 撤销后可以改走短路。

继续计算被跳过的操作数是教学练习允许的额外计算。Python 执行原式时会短路，不会执行其中的除法。提示和 `--trace` 使用短路参考顺序。

## 自然演绎

启动内置证明题可用 `--logic --proof mp`、`--logic --proof raa` 或 `--logic --proof identity`。也可以用 `--goal` 写目标、重复 `--premise` 写前提。

每行填写 `公式 ; 规则 ; 引用行`，三段用分号隔开，引用行号用逗号分开。前提依次编号为第 1 至第 n 行，后续每个被接受的步骤增加一行。`assume` 不引用行，第三段可以省略。

例如已有第 3 行 `A → B` 和第 5 行 `A`，写 `B ; mp ; 3,5` 可以引用它们。`A ; assume` 打开一个子证明。若第 4 行假设 `A`、子证明末行第 7 行得到 `C`，可写 `A → C ; imp-intro ; 4,7` 解除该假设。

| 规则 | 引用 | 得到 |
| --- | --- | --- |
| `assume` | 无 | 任意公式，作为新假设 |
| `mp` | `A → B` 和 `A` | `B` |
| `and-intro` | `A` 和 `B` | `A ∧ B` |
| `and-left` / `and-right` | `A ∧ B` | `A` / `B` |
| `or-left` / `or-right` | `A` / `B` | `A ∨ B` |
| `not-elim` | `A` 和 `¬A` | `⊥` |
| `bottom-elim` | `⊥` | 任意公式 |
| `imp-intro` | 假设行 `A`，子证明末行 `B` | `A → B` |
| `not-intro` | 假设行 `A`，子证明末行 `⊥` | `¬A` |
| `raa` | 假设行 `¬A`，子证明末行 `⊥` | `A` |
| `iff-intro` | `A → B` 和 `B → A` | `A ↔ B` |
| `iff-left` / `iff-right` | `A ↔ B` | `A → B` / `B → A` |
| `copy` | 任意一行 | 同一公式 |

`mp`、`not-elim`、`iff-intro` 的两条引用不分先后；`and-intro` 按引用顺序组成合取。`⊥` 和 `False` 都表示矛盾。

解除假设必须引用当前最内层假设及子证明末行，不能跨层解除、引用未来行或已关闭子证明中的行。结论出现在所有假设之外才算完成。`raa` 使用经典逻辑的反证法；尚无析取消去或自动证明搜索。语义等价不能替代推理规则检查。

## 非交互检查

以下命令均不读写练习进度：

```fish
cargo run --locked -- --python --trace 'False and (3 / 0 > 1)'
cargo run --locked -- --logic 'P -> Q' --equivalent '~P | Q'
cargo run --locked -- --logic --proof raa --check-proof 我的证明.json
```

`--trace` 显示一条短路参考求值路线；`--equivalent` 检查所有真值赋值下的逻辑等价。

`--check-proof` 读取学生自己写好的证明记录：JSON 字符串数组，每个元素是一行 `公式 ; 规则 ; 引用行`。它依次检查，遇到非法步骤或最终未证明目标时以错误退出。题目可由 `--proof` 选择，也可由 `--goal` / `--premise` 指定。这个文件是作答记录；题集文件仍使用 TOML。

## 输入范围

| 内容 | 上限 |
| --- | --- |
| 教学表达式源码 | 2048 字节 |
| Python 教学树 | 128 节点（含括号）、32 层 |
| 整数结果 | 4096 个二进制位 |
| 逻辑公式 | 128 个词法单元、32 层解析嵌套 |
| 等价检查 | 12 个命题变量 |
| 自然演绎 | 256 行、16 层假设 |

超过程序支持范围时会说明限制，不作为学生算错或 Python 异常处理。

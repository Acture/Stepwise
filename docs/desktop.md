# 使用桌面版

打开 Stepwise 后先选 Python 或命题逻辑。命题逻辑中也包含自然演绎题。需要从源码运行窗口时，先完成[桌面开发环境](development.md#运行桌面版)的安装。

## 选择、填写、检查

点击当前式中的一个运算单元，下方会出现带填空的新行。输入结果，按 `Enter` 检查。上方一直保留选择前的式子，已经完成的步骤逐行向上排列。

填错后输入会保留，可以直接修改；点错位置时会显示原因。括号内只剩一个值时，再点一下括号即可去掉它。可以先跟着[第一次练习](usage.md#完成第一次练习)做一遍。

未打开填空时，`↑↓` / `j k` 选择子式，`Enter` 开始填写，`u` 撤销，`r` 重做，`h` 提示，`?` 帮助。`Esc` 收起填空。填写期间，字符键都用于输入；中文输入法选字时按 `Enter` 不会提交答案。

自然演绎直接填写 `公式 ; 规则 ; 引用行`，`Enter` 检查，`Esc` 清空。点击窗口底部的「撤销一行」或「规则」按钮，可以撤销或查阅规则。规则名及引用方法见[自然演绎](reference.md#自然演绎)。

## 换题与导入题集

标题栏的 `‹ ›` 切换前后题目，`☰` 打开题目列表。列表中可以选择已有题目、随机出题、换语言，或打开一个 TOML 题集文件。

导入题集后，按文件顺序练习当前语言的题目，最后一题之后不会生成随机题。再次打开题目列表可以改选题目或随机练习。题集写法见[编写题集](question-sets.md)。

求值练习可用 `n` / `p` 换题；证明题中这些字母属于输入，换题使用 `Ctrl+N` / `Ctrl+P`。

## 更换外观

点标题栏右侧的齿轮打开设置，也可以从启动页底部进入。

- **皮肤**：选择黑板、练习本、终端或跟随系统浅深色的原生皮肤。支持的本机编辑器主题也会出现在列表中，或通过主题 JSON 文件导入。颜色会调整到可读的对比度。
- **字体**：界面文字和公式可以分别选。可跟随皮肤、跟随编辑器字体，或选择已安装字体。缺少逻辑符号的字体会显示提示，缺字由后备字体补齐。

每组设置支持 `Tab` 聚焦、方向键移动、空格或 `Enter` 选中。设置面板打开时，按键不会传给后面的题目。

外观自动保存在默认进度文件旁的 `appearance.json`。它不影响题目和判题，也不随进度路径改变。

## 继续终端里的练习

关闭终端练习后，再打开窗口并选择相同语言，可以继续未完成的题；反过来也一样。两端默认使用同一份进度，请避免同时打开两个实例修改它。

桌面程序支持 `--progress-file PATH` 指定另一个进度文件，或 `--no-save` 临时练习。以 macOS 已安装应用为例：

```fish
open /Applications/Stepwise.app --args --no-save
```

这些参数只控制答题进度，外观设置仍会保存。

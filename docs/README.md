# Stepwise 公开文档

这里维护面向使用者与贡献者的文档，随 Stepwise 代码仓库提交。普通 clone 即可阅读，不需要私有笔记仓库权限。

- [使用说明](../README.md)：终端与桌面操作、TOML 题集、符号与自然演绎、进度保存。
- [开发与架构](development.md)：源码职责、构建、检查与类型声明生成。
- [分发与验收](distribution.md)：CLI 归档、桌面安装包、许可证与运行验收。
- [实现与验证证据](../STATUS.md)：已实现范围和可重跑的验证入口。

`notes/` 是私有设计与规划的 submodule，保存设计理由、草稿、未采纳方案和内部规划。公开说明在这里维护，不把私有笔记直接发布或复制为第二份设计记录。任务、依赖和状态由 Linear 维护；仓库约定由 [CLAUDE.md](../CLAUDE.md) 维护，`AGENTS.md` 指向同一文件。
